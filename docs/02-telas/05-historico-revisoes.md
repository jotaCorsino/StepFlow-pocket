# Tela 05 — Histórico de Revisões

Mostra revisões do Procedimento em ordem temporal.

Cada entrada exibe pelo menos:

- versão editorial;
- número técnico da revisão quando útil;
- data/hora local registrada;
- Responsável textual;
- resumo da alteração;
- status/publicação.

Ações: visualizar revisão, comparar informações essenciais quando implementado e iniciar nova revisão a partir da vigente. Histórico não é editado retroativamente.
