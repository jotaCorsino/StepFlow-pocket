# Tela 01 — Shell e Dashboard

Ao abrir o StepFlow, o usuário entra diretamente no aplicativo.

## Sidebar

- logo StepFlow no topo;
- Dashboard;
- Procedimentos;
- Atendimentos;
- Equipamentos;
- Configurações;
- Exportar / Importar dados.

Sem avatar, conta, login/logout ou indicador online.

## Dashboard

Resumo local e leve:

- Procedimentos publicados/ativos;
- Atendimentos em andamento;
- Atendimentos recentes;
- acessos rápidos para criar Procedimento e Atendimento;
- aviso discreto quando nunca houve exportação de dados ou quando a última exportação é antiga, se essa preferência estiver habilitada.
