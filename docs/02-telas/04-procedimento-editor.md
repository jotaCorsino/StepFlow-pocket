# Tela 04 — Editor de Procedimento

## Campos

- Código;
- Título;
- Área / Departamento;
- Responsável;
- Status;
- Versão;
- Objetivo;
- Observações;
- Pré-requisitos;
- Categorias;
- Etapas;
- Histórico/resumo da alteração da revisão.

## Etapas

O editor permite adicionar, remover e reordenar Etapas e passos. Blocos de instrução/comando são estruturados para manter cópia confiável e apresentação clara.

## Salvamento

Salvar é explícito. Revisões históricas não são sobrescritas silenciosamente. Alterar um Procedimento já publicado gera nova revisão conforme o fluxo vigente.

Categoria arquivada herdada aparece com indicação visual e pode ser removida, mas não adicionada novamente enquanto arquivada.
