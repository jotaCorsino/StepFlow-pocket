# Política de capacidade Codex — StepFlow

Usar a menor capacidade suficiente para executar a tarefa com segurança.

## Baixa

- documentação pequena;
- ajustes locais de HTML/CSS;
- testes isolados;
- refactors simples.

## Média

- feature completa local;
- IndexedDB/migrations;
- importação/exportação;
- service worker/PWA;
- build e testes integrados.

## Alta

Reservar para mudanças transversais que realmente cruzem vários subsistemas ou investigação de blocker técnico.

Capacidade maior não autoriza ampliar escopo, inventar requisito ou alterar decisões vigentes.
