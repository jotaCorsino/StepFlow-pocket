# Tarefas Codex

Somente tarefas técnicas aprovadas entram aqui.

Cada tarefa deve informar:

- objetivo;
- base/branch/SHA;
- arquivos permitidos;
- decisões vigentes;
- critérios de aceite;
- comandos de validação;
- itens explicitamente fora do escopo.

Nenhuma tarefa futura fica autorizada apenas porque aparece no roadmap.
